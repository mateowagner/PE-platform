# PE-platform

Liga Pulpito Esports — Plataforma web para gestión de torneos y ligas de League of Legends.

## Stack

- **Backend:** NestJS + PostgreSQL + TypeORM
- **Frontend:** React 18 + TypeScript + Vite
- **Infra:** Docker Compose

## Estructura

- `pe-api/` → Backend NestJS
- `pe-web/` → Frontend React
